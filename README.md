# 🚀 ABOUT THE PROJECT

QRcryptX is a secure file sharing application that enables users to share encrypted files through QR codes.  
The platform uses **AES Encryption** to protect files and ensures secure and fast file transfer between devices.

---

# ✨ FEATURES

- 🔒 AES Encrypted File Sharing
- 📷 QR Code Generation for File Access
- 📁 Secure File Upload & Download
- ⚡ Fast and Lightweight Application
- 🌐 Responsive User Interface
- 🛡️ Privacy-Focused File Transfer

# ⚙️ HOW IT WORKS

1️⃣ User uploads a file  
2️⃣ File gets encrypted using AES Encryption  
3️⃣ Secure link is generated  
4️⃣ QR Code is created for the file  
5️⃣ User scans QR code to securely access/download file

---

# 🔐 AES ENCRYPTION

QRcryptX uses **AES (Advanced Encryption Standard)** to encrypt files before sharing them.  
This ensures secure communication and protects sensitive data from unauthorized access.
